# ⚽ FootballPredictor - Аналитика и Прогнозирование Футбольных Матчей

Интеллектуальное веб-приложение для анализа и прогнозирования результатов футбольных матчей чемпионата мира.

## 🎯 Возможности

✅ **Анализ матчей** - детальная статистика команд  
✅ **Прогнозы** - предсказание исходов (1X2, голы, обе забьют)  
✅ **Вероятности** - процентные вероятности каждого исхода  
✅ **Графики** - визуализация статистики  
✅ **История** - сохранение всех прогнозов  
✅ **Реальные данные** - интеграция с API-FOOTBALL  

## 🛠️ Технологический стек

### Frontend
- ⚛️ React 18 + TypeScript
- 🎨 TailwindCSS
- 📊 Recharts для графиков

### Backend
- 🟩 Node.js + Express
- 🗄️ SQLite
- 📡 API-FOOTBALL интеграция

## 🚀 Установка

1. **Backend установка**
```bash
cd backend
npm install
cp .env.example .env
npm run dev
```

2. **Frontend установка** (новый терминал)
```bash
cd frontend
npm install
npm start
```

3. Откройте `http://localhost:3000`
